# Screenshots

Live screenshots of this design could not be reliably captured by the export tool.
To capture your own:

1. Open `Progress Note Writer.html` in any modern browser.
2. The design renders responsively — capture at 1440px wide for desktop and 390px for mobile.
3. Key states to capture:
   - Default empty state (note pane shows "Your note will appear here")
   - Sidebar scrolled to show MSE + risk panels
   - With a generated note on the paper
   - Confirmation modal ("Erase everything?")
   - Tweaks panel open (toggle in toolbar)
   - Mobile width with "Jump to note" pill visible

Drop the resulting PNGs into this folder before zipping the handoff.
